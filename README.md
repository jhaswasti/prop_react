# Dynamic Card Component with Gradient Borders

A responsive React application featuring a reusable card component that dynamically renders properties passed via props, styled with custom gradient borders in a modern dark theme.

## 📌 Features

- **Reusable Card Component:** Modular architecture rendering card details dynamically through React props.
- **Gradient Border Styling:** Custom CSS linear gradients applied to card containers for a modern UI aesthetic.
- **Dynamic Data Generation:** Generates 21 dynamic items using `Array.from()` for seamless list mapping.
- **Responsive Grid Layout:** Built using CSS Grid (`repeat(auto-fill, minmax(...))`) to ensure flawless display across all viewports.
- **Hover Micro-interactions:** Smooth UI elevation effects when hovering over individual cards.

## 🛠️ Tech Stack

- **Frontend Library:** React.js
- **Styling:** CSS3 (Flexbox & CSS Grid)
- **Tooling:** Create React App

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### 1. Prerequisites
Ensure you have **Node.js** and **npm** installed on your system.

### 2. Installation
Clone or extract the repository, then navigate to the project directory:
1. npm install.
2. npm start.
